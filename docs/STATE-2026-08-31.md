## Journal / self-model

The Journal Instrument is a sensor attached to real work, not an app.

Pre-task predictions include p50/p90 human time, blocking-human-input expectation, cheap-model sufficiency, first-pass acceptability and confidence. The `cheap` dimension uses forced off-policy draws so capability can be estimated independently of routing policy.

`score.py` refuses headline metrics below 20 resolved rows. Stronger self-model claims require more evidence and must beat trivial baselines. No self-model claims exist yet.
